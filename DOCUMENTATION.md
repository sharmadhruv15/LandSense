# Himalayan Landslide Detection - Complete Documentation 🏔️

Welcome to the official documentation for the **Himalayan Landslide Detection System**. This AI-powered application is designed to analyze remote sensing images and detect landslide risks in highly vulnerable mountain regions, specifically tailored for the Himalayas.

---

## 1. System Architecture

The application is built using a modern, lightweight tech stack designed for both rapid inference and clear visualization.

- **Frontend**: HTML5, CSS3 (Glassmorphism design), and Vanilla JavaScript.
- **Backend**: Python, Flask (RESTful API).
- **Machine Learning**: PyTorch, U-Net Architecture.
- **Image Processing & Visualization**: NumPy, SciPy, Pillow, Matplotlib.

---

## 2. Core Features

### 2.1 The 6-Panel Analytical Dashboard

When a user uploads a satellite image, the backend processes it and generates a comprehensive 6-panel analytical dashboard that gives a full breakdown of the terrain:

1.  **RGB Image**: The original satellite image uploaded by the user.
2.  **Slope Analysis**: A simulated terrain gradient map using Sobel edge detection to highlight steep drops where landslides are mechanically more likely to trigger.
3.  **Elevation (DEM)**: A simulated Digital Elevation Model highlighting high peaks and low valleys.
4.  **Model Landslide Probability**: The raw heatmap generated by the U-Net model representing pixel-by-pixel probabilities.
5.  **Final Categorical Risk Map**: A clear, color-coded map mapping safe zones (Green) to danger zones (Red).
6.  **Risk Legend**: A reference key for understanding the categorical map.

### 2.2 U-Net Deep Learning Model

The core predictive engine is a PyTorch-based **U-Net architecture**.

- **Input**: The model is built to accept 14-channel multispectral satellite data (trained on the _Landslide4Sense_ dataset).
- **Adaptation**: Since end-users typically upload standard 3-channel RGB images, the backend automatically approximates and repeats the channels to fit the model's expected 14-channel input tensor.
- **Output**: A softmax probability map highlighting the exact pixels where landslide signatures are detected.

### 2.3 Heuristic Fallback Engine

If the trained model weights (`best_unet.pth`) are not found on the server, the system automatically falls back to an advanced heuristic engine. This engine calculates risk based on:

- **Vegetation Density**: Using green-channel dominance logic.
- **Bare Rock Exposure**: Using red-channel dominance thresholds.
- **Terrain Brightness**: To estimate exposure.
- _Logic_: Areas with steep slopes (high bare rock) and zero vegetation are flagged as highly vulnerable to landslides during heavy rains.

## 3. Setup & Installation Guide

### Prerequisites

- Python 3.8+
- Pip package manager

### Installation Steps

1.  **Clone the Repository**

    ```bash
    git clone https://github.com/yourusername/Himalayan_Landslide_Detection.git
    cd Himalayan_Landslide_Detection
    ```

2.  **Install Dependencies**
    It is highly recommended to use a virtual environment (`venv` or `conda`).

    ```bash
    pip install -r requirements.txt
    ```

3.  **Add Model Weights (Optional but Recommended)**
    Ensure your trained PyTorch weights are placed in the following directory:
    `outputs/checkpoints/best_unet.pth`

4.  **Start the Server**
    ```bash
    python app.py
    ```
    The server will start locally. Access the web interface at `http://localhost:5000`.

## 4. Risk Level Classification

The system classifies landslide risk into four levels based on terrain features:

- **LOW RISK**: Safe areas with good vegetation cover and low bare rock exposure (Risk Score: 0-25)
- **MODERATE RISK**: General areas with mixed terrain characteristics (Risk Score: 25-50)
- **HIGH RISK**: Areas with significant bare rock and reduced vegetation - including UCE region (Risk Score: 50-70)
- **VERY HIGH RISK**: Extremely vulnerable areas with minimal vegetation and steep slopes (Risk Score: 70-100)

### Risk Assessment Factors

The system analyzes the following terrain features:

- **Vegetation Density**: Green vegetation coverage percentage
- **Bare Rock Exposure**: Areas with exposed rock and minimal vegetation
- **Terrain Slope**: Calculated from image gradients to identify steep zones

## 5. API Reference

The backend exposes a REST API that can be consumed by mobile apps or other web services.

### `POST /analyze`

Analyzes an uploaded image and returns risk metrics and base64-encoded visualizations.

**Request Payload:**

- `multipart/form-data` containing an `image` file.

**Response (JSON):**

```json
{
  "place": "Analyzed Region (AI Detection)",
  "risk_level": "HIGH",
  "risk_score": 55.2,
  "factors": "Vegetation: 25%, Bare Rock: 60%, Slope-based analysis indicates high-risk terrain",
  "recommendation": "CAUTION - High landslide risk detected in this region",
  "risk_map": "<base64_string_of_risk_overlay>",
  "dashboard_map": "<base64_string_of_6_panel_dashboard>",
  "image_analysis": {
    "dimensions": "800x600px",
    "aspect_ratio": 1.33,
    "vegetation_pct": 25.0,
    "bare_rock_pct": 60.0,
    "water_pct": 0.0,
    "brightness": 125.4
  }
}
```
